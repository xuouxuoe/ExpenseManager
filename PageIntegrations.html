วิธีเชื่อม LINE
  1. LINE Developers → Messaging API: ออก Channel access token แล้วกด "ตั้ง token" ด้านบน
  2. สร้างการเชื่อมต่อด้านล่าง สิทธิ์ บันทึก (WRITE) และใส่ LINE userId ของผู้ที่ใช้ได้ (ถ้ายังไม่รู้ userId ให้ทักบอทก่อน บอทจะตอบ userId กลับมา)
  3. ตั้ง Webhook URL เป็น <URL /exec ของ gateway>?line_key=<API key ของการเชื่อมต่อนั้น> แล้วเปิด Use webhook และปิดข้อความตอบกลับอัตโนมัติ
  4. ปุ่ม Verify ใน LINE แจ้ง "302 Found" เพราะ Apps Script ตอบแบบ redirect เสมอ แต่ข้อความจริงยังทำงาน ให้เปิด Use webhook ปิด Webhook redelivery แล้วทดสอบด้วยการพิมพ์ในแชต
  5. ถ้าบอทไม่ตอบ ดู log ที่โปรเจกต์ gateway → การดำเนินการ (Executions) → doPost: LINE_WEBHOOK: UNAUTHORIZED = key ใน URL ผิด, FORBIDDEN_SCOPE = ไม่มีสิทธิ์ WRITE, FORBIDDEN_CHANNEL = ไม่ได้ใส่ LINE userId (บอทตอบ userId ให้ในแชต), LINE_NOT_CONFIGURED = ยังไม่ได้ตั้ง token

API key อยู่ใน Webhook URL — เก็บเป็นความลับ ถ้าสงสัยว่ารั่วให้กด "เปลี่ยน key" แล้วแก้ URL ใน LINE
