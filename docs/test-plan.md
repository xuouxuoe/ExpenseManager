# Test Plan — Expense Manager V2

## การ์ดและตารางแผนที่บันทึกแล้ว (local)

- ตรวจการ์ดพื้นสีและขอบแยกตามประเภท และสลับมุมมองตารางด้วยข้อมูลจำลอง
- แผนประกัน 8,500 บาทและโทรศัพท์ 12,000 บาท รวมยอดแผน 20,500 บาท ชำระแล้ว 2,000 บาท คงเหลือ 18,500 บาท กันไว้ 800 บาท ตัวเลขตรงทั้งสองมุมมอง
- ทดสอบเปิดดูงวดแล้วสลับมุมมอง ยังคงสถานะเปิดของแผน เปิด dialog จัดการจากตาราง และติดดาวจากตารางได้
- เปิดฟอร์มสร้างแผนใหม่แล้วส่วนแผนที่บันทึกแล้วซ่อน ปิดฟอร์มแล้วกลับมาแสดง และ reload หน้ายังจำมุมมองตารางได้
- ตรวจ viewport 375px พบตารางกว้าง 1,152px อยู่ภายในพื้นที่เลื่อน 326px หน้าเว็บไม่ล้นตามความกว้างตาราง

## สร้างแผนทันที (local)

- ทดสอบในเบราว์เซอร์ด้วยข้อมูลจำลอง กดสร้างโดยยังไม่กรอกข้อมูลต้องแสดง validation
- กรอกเงินต้น 1,000 บาท 3 งวด ดอกเบี้ยคงที่ 10% ต่อปี ค่าธรรมเนียม 2% เก็บงวดแรก กดสร้างแผนทันทีแล้วได้แผนหนึ่งรายการ ยอดงวด 361.66 / 341.66 / 341.68 บาท
- เส้นทางดูตัวอย่างงวดและยืนยันบันทึก 600 บาทผ่าน
- ใช้ local proxy จำลอง HTTP 503 หลัง backend บันทึกสำเร็จ ปุ่มสร้างแผนทันทีเปิดให้ลองใหม่โดยคง payload เดิม ฟอร์มถูกล็อกระหว่างรอยืนยัน กดซ้ำแล้วอ่านกลับพบหนึ่งแผนเท่านั้น
- ผลทดสอบทั้งหมดในชุด npm test ผ่าน 109/109 การตรวจปุ่มใหม่ทำผ่าน local browser ยังไม่ทดสอบบน /dev

## 7. Non-functional

- การเขียนพร้อมกัน 2 session (LockService)
- Backend ล้มเหลว / timeout → UI แสดง error และ retry ด้วย key เดิม
- ผู้ใช้ไม่มีสิทธิ์ → ปฏิเสธที่ Backend
- มือถือ: ฟอร์มสร้างแผนและรายการใช้งานได้ที่ 375px
- เวลา refresh ชื่อเมื่อข้อมูล 10,000+ แถว ต่ำกว่าขีดจำกัดเวลา Apps Script
