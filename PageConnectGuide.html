คู่มือเชื่อมต่อภายนอก (สำหรับมือใหม่)

ทำตามทีละขั้นเพื่อบันทึกรายรับรายจ่ายผ่านแชต Telegram หรือ LINE โดยไม่ต้องเขียนโค้ด — ใช้เวลาประมาณ 15–20 นาที

สารบัญ

  1. ภาพรวม: ระบบทำงานอย่างไร
  2. เตรียมก่อนเริ่ม (gateway และ API key)
  3. ตั้งค่า AI
  4. เชื่อม Telegram
  5. เชื่อม LINE
  6. ใช้งานประจำวันและการยืนยัน
  7. แก้ปัญหาที่พบบ่อย
  8. ความปลอดภัย

1. ภาพรวม: ระบบทำงานอย่างไร

  1. คุณพิมพ์ในแชต เช่น "กาแฟ 65" หรือส่งรูปสลิป
  2. Telegram/LINE ส่งข้อความต่อ ไปที่ "gateway" (ลิงก์ Apps Script ที่ลงท้าย /exec) พร้อม API key ที่อยู่ในลิงก์
  3. AI แปลงข้อความ เป็นร่างรายการ (จำนวนเงิน หมวด บัญชี) — ยังไม่บันทึก
  4. บอทตอบสรุปพร้อมปุ่ม "ยืนยัน" / "ยกเลิก" — หรือยืนยันที่หน้าเว็บ เมนู รอยืนยัน
  5. กดยืนยันแล้วจึงบันทึกจริง ร่างที่ไม่ยืนยันจะหมดอายุใน 24 ชั่วโมง

คำศัพท์ที่ต้องรู้

Gateway
Web App ของ Apps Script ที่เปิดให้ Telegram/LINE ส่งข้อความเข้ามาได้โดยไม่ต้องล็อกอิน (แยกจากหน้าเว็บนี้)
การเชื่อมต่อ / API key
"กุญแจ" ที่ระบุว่าใครเรียกเข้ามา สร้างได้ที่หน้า เชื่อมต่อภายนอก แสดงครั้งเดียว
Bot token / Channel access token
รหัสที่ให้ระบบตอบกลับในแชตได้ ได้จาก @BotFather (Telegram) หรือ LINE Developers
ผู้ใช้ที่อนุญาต
รหัสบัญชีแชตที่บันทึกได้ เช่น tg_123456789 (Telegram) หรือ U… (LINE) — คนอื่นที่ทักบอทจะถูกปฏิเสธ

2. เตรียมก่อนเริ่ม

2.1 หา URL ของ gateway

  1. เปิดโปรเจกต์ Apps Script ที่เป็น gateway (ผู้ดูแลระบบตั้งไว้แล้ว) → ปุ่ม Deploy → Manage deployments
  2. คัดลอก Web app URL ที่ลงท้ายด้วย /exec (ไม่ใช่ /dev)
  3. ถ้าสร้าง deployment ใหม่ URL จะเปลี่ยน — ต้องตั้ง webhook ใหม่ทุกครั้ง

2.2 สร้างการเชื่อมต่อ (API key)

  1. ไปหน้า เชื่อมต่อภายนอก → + เพิ่มการเชื่อมต่อ
  2. ตั้งชื่อ เช่น "Telegram ของฉัน" เลือกสิทธิ์ ดูข้อมูล (READ) และ บันทึกผ่านร่าง (WRITE)
  3. เลือก บัญชีเริ่มต้น และ เจ้าของเริ่มต้น (ใช้เมื่อข้อความไม่ได้บอกว่าจ่ายจากบัญชีไหน)
  4. ช่อง "ผู้ใช้แชตที่อนุญาต" เว้นว่างไว้ก่อน (จะได้รหัสจากบอทในขั้นถัดไป)
  5. กดบันทึก แล้ว คัดลอก API key (emk_…) เก็บไว้ — ระบบแสดงครั้งเดียว ถ้าหายให้กด "เปลี่ยน key"

3. ตั้งค่า AI (เจ้าของระบบ ทำครั้งเดียว)

ไปหน้า เชื่อมต่อภายนอก → การ์ด "ผู้ให้บริการ AI" → ตั้งค่า เลือกแบบใดแบบหนึ่ง

แบบ A: API key (แนะนำ เสถียรที่สุด)

  1. สมัคร/ล็อกอิน platform.openai.com (หรือ Anthropic / Gemini) แล้วเติมเครดิต
  2. สร้าง API key แล้วคัดลอก
  3. ในระบบ เลือกผู้ให้บริการ ใส่ชื่อโมเดล (เช่น gpt-4o-mini) และวาง key → บันทึก
  4. กด ทดสอบ ต้องขึ้น "เชื่อมต่อสำเร็จ"

เสียค่าใช้จ่ายตามจำนวนข้อความ (ข้อความสั้นมาก ปกติไม่กี่สตางค์ต่อรายการ)

แบบ B: เข้าสู่ระบบด้วยบัญชี ChatGPT (แบบ Codex)

  1. ต้องมี ChatGPT Plus / Pro / Team
  2. ใน ChatGPT → Settings → Security เปิดการอนุญาต device code สำหรับ Codex (ถ้ามีตัวเลือกนี้)
  3. ในระบบ เลือกผู้ให้บริการ ChatGPT (เข้าสู่ระบบแบบ Codex) ใส่โมเดล เช่น gpt-5 → บันทึก
  4. กด เข้าสู่ระบบ ChatGPT → ระบบแสดงรหัส 8 ตัว → กด "เปิดหน้าเข้าสู่ระบบ OpenAI" → ล็อกอินและกรอกรหัส
  5. รอหน้าเว็บขึ้น "เข้าสู่ระบบ ChatGPT แล้ว" แล้วกด ทดสอบ

⚠️ ใช้ช่องทางภายในเดียวกับ Codex CLI ไม่ใช่ API สาธารณะ — อาจขัดเงื่อนไขของ OpenAI และหยุดทำงานได้ทุกเมื่อ ใช้โควตาของบัญชี ChatGPT ถ้าทดสอบไม่ผ่านให้ใช้แบบ A

4. เชื่อม Telegram (ง่ายที่สุด)

  1. ขั้นที่ 1 — สร้างบอท

    ในแอป Telegram ค้นหา @BotFather (มีเครื่องหมายยืนยันสีฟ้า) → พิมพ์ /newbot → ตั้งชื่อบอท → ตั้ง username ที่ลงท้ายด้วย bot เช่น myhome_expense_bot

    BotFather จะส่ง token หน้าตาแบบ 123456789:AAH… มาให้ — คัดลอกไว้ (อย่าส่งให้คนอื่น)

  2. ขั้นที่ 2 — ใส่ token ในระบบ

    หน้า เชื่อมต่อภายนอก → การ์ด "Telegram Bot" → ตั้ง bot token → วาง token → บันทึก (ระบบตรวจกับ Telegram ให้ และแสดงชื่อ @บอท)

  3. ขั้นที่ 3 — ตั้ง webhook

    กด ตั้ง webhook → วาง URL /exec ของ gateway (ข้อ 2.1) และ API key ของการเชื่อมต่อ (ข้อ 2.2) → ตั้ง webhook

  4. ขั้นที่ 4 — อนุญาตบัญชี Telegram ของคุณ

    เปิดแชตกับบอท (ลิงก์ "เปิดแชตกับบอท" ในการ์ด) → กด Start หรือพิมพ์อะไรก็ได้ → บอทตอบรหัส tg_… กลับมา

    กลับไปหน้าเชื่อมต่อภายนอก → การเชื่อมต่อที่สร้างไว้ → แก้ไข → วางรหัส tg_… ในช่อง "ผู้ใช้แชตที่อนุญาต" (หลายคนคั่นด้วยจุลภาค) → บันทึก

  5. ขั้นที่ 5 — ทดสอบ

    พิมพ์ วิธีใช้ บอทต้องตอบตัวอย่าง → พิมพ์ กาแฟ 65 → ตรวจสรุป → กด ✅ ยืนยัน → ดูรายการที่หน้า รายการ

ใช้ได้เฉพาะแชตส่วนตัวกับบอท (ไม่รองรับกลุ่ม) · ถ้าบอทไม่ตอบ ดู "ผลล่าสุดจาก Telegram" ในการ์ด และหัวข้อ 7

5. เชื่อม LINE Official Account

  1. สร้าง LINE Official Account และเปิด Messaging API ที่ LINE Developers Console
  2. แท็บ Messaging API → ออก Channel access token (long-lived) → ในระบบกด "ตั้ง token" ในการ์ด LINE แล้ววาง
  3. ตั้ง Webhook URL เป็น <URL /exec ของ gateway>?line_key=<API key> → เปิด Use webhook → ปิดข้อความตอบกลับอัตโนมัติใน LINE Official Account Manager
  4. ทักบอทในแชต LINE → บอทตอบ LINE userId (U…) → ใส่ในช่อง "ผู้ใช้แชตที่อนุญาต" ของการเชื่อมต่อ
  5. ปุ่ม Verify ของ LINE จะขึ้น "302 Found" เป็นเรื่องปกติของ Apps Script ให้ทดสอบด้วยการพิมพ์ในแชตแทน

6. ใช้งานประจำวันและการยืนยัน

ตัวอย่างข้อความ

  • ข้าวกลางวัน 120
  • เติมน้ำมัน 1500 บัตร KTC
  • เงินเดือนเข้า 30000
  • โอนจาก kbank ไป scb 500
  • ผ่อนทีวี 12000 10 เดือน บัตร KTC (สร้างแผนชำระ)
  • ส่งรูปสลิปโอนเงิน/ใบเสร็จ

คำสั่งดูข้อมูล (ไม่ใช้ AI)

  • สรุป — รายรับรายจ่ายเดือนนี้
  • ยอดเงิน — ยอดบัญชีและเงินที่ใช้ได้
  • ล่าสุด — 5 รายการล่าสุด
  • งบ — งบใช้จ่ายคงเหลือ
  • หนี้ — ยอดหนี้บัตร วงเงินคงเหลือ และยอดต้องจ่ายเดือนนี้

ลืมกดยืนยันในแชต? เปิดเมนู รอยืนยัน บนหน้าเว็บ จะเห็นร่างทั้งหมดที่ยังไม่บันทึก พร้อมคำเตือนรายการที่อาจซ้ำ กดยืนยันหรือยกเลิกได้ทันที (กดซ้ำทั้งในแชตและหน้าเว็บก็บันทึกเพียงครั้งเดียว)

7. แก้ปัญหาที่พบบ่อย

อาการ / ผลล่าสุดวิธีแก้
บอทเงียบ ไม่มี "ผลล่าสุด" เลยwebhook ยังไม่ได้ตั้งหรือ URL ผิด — กด "ตั้ง webhook" ใหม่ ตรวจว่า URL ลงท้าย /exec ของ gateway
UNAUTHORIZEDAPI key ผิด ถูกเปลี่ยน หรือการเชื่อมต่อถูกปิด — ตั้ง webhook ใหม่ด้วย key ล่าสุด
FORBIDDEN_CHANNEL / forbiddenยังไม่ได้ใส่รหัส tg_… หรือ U… ที่บอทตอบมา ในช่องผู้ใช้แชตที่อนุญาต
FORBIDDEN_SCOPEการเชื่อมต่อไม่มีสิทธิ์ WRITE (บันทึก) หรือ READ (คำสั่งดูข้อมูล)
TELEGRAM_HTTP_401 / LINE_REPLY_HTTP_401token ของบอทผิดหรือถูกเปลี่ยน — ตั้ง token ใหม่
ข้อความมี script.external_requestgateway ไม่มีสิทธิ์ออกอินเทอร์เน็ต — ผู้ดูแลต้อง Run ฟังก์ชันใน editor เพื่ออนุญาต แล้ว deploy gateway ใหม่ (และตั้ง webhook ใหม่)
"ระบบยังไม่ได้ตั้งค่า AI"ทำหัวข้อ 3 แล้วกด "ทดสอบ" ให้ผ่าน
Telegram แจ้ง 302 Moved Temporarilyเป็นข้อจำกัดของ Apps Script ข้อความยังถูกประมวลผล และระบบข้ามข้อความที่ส่งซ้ำ
ChatGPT: "การเข้าสู่ระบบหมดอายุ"กด "เข้าสู่ระบบใหม่" ในการ์ด AI (เช่น เมื่อออกจากระบบ ChatGPT ทุกอุปกรณ์หรือเปลี่ยนรหัสผ่าน)

8. ความปลอดภัย

  • API key อยู่ในลิงก์ webhook — อย่าแชร์ลิงก์นั้น ถ้าสงสัยว่ารั่วให้กด "เปลี่ยน key" แล้วตั้ง webhook ใหม่
  • ใส่ผู้ใช้แชตที่อนุญาตเสมอ คนอื่นที่ทักบอทจะบันทึกไม่ได้
  • ทุกการบันทึกจากแชตต้องกดยืนยัน AI ไม่บันทึกเอง
  • ข้อความแชตและรายชื่อบัญชี/หมวดถูกส่งให้ผู้ให้บริการ AI ที่เลือก (ไม่ส่งยอดเงินคงเหลือ) และ Telegram/LINE เห็นข้อความที่คุณพิมพ์
  • token ทั้งหมด (bot, LINE, AI, ChatGPT) เก็บใน Script Properties ไม่แสดงกลับบนหน้าเว็บ — ผู้ที่มีสิทธิ์แก้โปรเจกต์ Apps Script เห็นค่าได้
